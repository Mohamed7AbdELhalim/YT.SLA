## 📋 نظرة عامة

أداة ويب تفاعلية + سكربت بايثون لأرشفة فيديوهات يوتيوب. صُممت خصيصاً للأرشفة الضخمة (**1000+ فيديو**) مع:

- 🏷️ **تصنيف تلقائي** بالوسوم والمجلدات
- 🔒 **حماية الخصوصية** بإزالة معاملات التتبع
- 📅 **تصنيف زمني** بالأسبوع واليوم
- 📤 **تصدير/استيراد** بصيغة JSON
- 🐍 **مولّد سكربت بايثون** جاهز للاستخدام

## ✨ الميزات

### 🔗 إدارة الروابط
| الميزة | الوصف |
|--------|-------|
| تنظيف الروابط | إزالة `?si=`, `&feature=`, `&fbclid=` وغيرها |
| تحويل تلقائي | تحويل `youtu.be` → `youtube.com` |
| إزالة التكرار | حذف الروابط المكررة تلقائياً |
| جلب العناوين | استخراج عنوان كل فيديو من يوتيوب |

### 🏷️ التصنيف الذكي
| الميزة | الوصف |
|--------|-------|
| وسم الموقع | `#youtube`, `#vimeo`, إلخ |
| وسم المسار | `#shorts`, `#playlist`, `#channel` |
| المجلدات | تنظيم حسب نوع المحتوى |
| أوسمة مخصصة | إضافة أوسمة يدوية لكل رابط |

### 📅 التصنيف الزمني
| الميزة | الوصف |
|--------|-------|
| استخراج التاريخ | من الرابط إن وُجد |
| تاريخ يدوي | إمكانية تحديد تاريخ لكل رابط |
| رقم الأسبوع | حساب تلقائي حسب ISO 8601 |
| بدون تاريخ | تصنيف خاص للروابط بدون تاريخ |

### 💾 التخزين والنقل
| الميزة | الوصف |
|--------|-------|
| LocalStorage | حفظ تلقائي في المتصفح |
| تصدير JSON | تنزيل ملف كامل بكل البيانات |
| استيراد JSON | تحميل بيانات من أي جهاز |
| استمرارية | البيانات لا تُحذف عند إغلاق الصفحة |

## 🚀 البدء السريع

### الطريقة 1: استخدام واجهة الويب

```bash
# 1. استنسخ المشروع
git clone https://github.com/username/youtube-archiver.git

# 2. افتح الواجهة
open index.html
# أو اسحب الملف للمتصفح
```

### الطريقة 2: استخدام سكربت بايثون

```bash
# 1. ثبّت المتطلبات
pip install yt-dlp

# 2. أنشئ ملف الروابط
cat > urls.txt << EOF
https://www.youtube.com/watch?v=VIDEO_ID_1
https://www.youtube.com/watch?v=VIDEO_ID_2
https://www.youtube.com/playlist?list=PLAYLIST_ID
EOF

# 3. شغّل الأداة
python youtube_archiver.py \
  --urls-file urls.txt \
  --output-dir ./archive \
  --max-concurrent 2
```

## 🔧 الإعدادات المتقدمة

### خيارات سكربت بايثون

```bash
python youtube_archiver.py \
  --urls-file urls.txt \           # ملف الروابط
  --output-dir ./archive \         # مجلد الحفظ
  --max-concurrent 4 \             # تحميلات متوازية
  --format "bestvideo+bestaudio"   # صيغة الجودة
```

### صيغ الجودة المتاحة

| الصيغة | الوصف |
|--------|-------|
| `bestvideo+bestaudio` | أعلى جودة (افتراضي) |
| `bestvideo[height<=1080]+bestaudio` | 1080p كحد أقصى |
| `bestvideo[height<=720]+bestaudio` | 720p كحد أقصى |
| `bestaudio/best` | صوت فقط |

## 🛠️ استكشاف الأخطاء

### مشكلة: زر التصدير لا يعمل
```
✅ الحل: تأكد من وجود روابط في الجدول أولاً
         (اضغط "تنظيف + تصنيف الروابط")
```

### مشكلة: HTTP Error 429
```
✅ الحل: قلل عدد التحميلات المتوازية
         --max-concurrent 1
```

### مشكلة: Video unavailable
```
✅ الحل: الفيديو محذوف أو خاص
         تحقق من صلاحية الرابط
```
