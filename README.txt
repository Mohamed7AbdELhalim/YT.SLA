هذا المشروع عبارة عن أداة ويب تفاعلية + سكربت بايثون لأرشفة فيديوهات
يوتيوب بشكل منظم واحترافي. تم تصميمها خصيصاً للأرشفة الضخمة (1000+ فيديو)
مع دعم كامل للغة العربية.

الأداة تتيح لك:
  • إدارة مئات أو آلاف الروابط بسهولة
  • تنظيف الروابط من معاملات التتبع (?si=، &feature=، إلخ)
  • تصنيف تلقائي بالوسوم والمجلدات
  • جلب عناوين الفيديوهات من يوتيوب
  • تصدير/استيراد البيانات بصيغة JSON
  • توليد سكربت بايثون جاهز للتحميل

================================================================================
                          المتطلبات الأساسية
================================================================================

لاستخدام واجهة الويب (index.html):
─────────────────────────────────────
  • متصفح ويب حديث (Chrome, Firefox, Safari, Edge)
  • اتصال بالإنترنت (لـ Tailwind CSS CDN وجلب العناوين)

لاستخدام سكربت بايثون المولَّد:
─────────────────────────────────────
  • Python 3.8 أو أحدث
  • مكتبة yt-dlp (تُثبَّت بالأمر: pip install yt-dlp)
  • FFmpeg (لدمج الفيديو والصوت) - اختياري لكن موصى به

================================================================================
                           طريقة الاستخدام
================================================================================

الخطوة 1: فتح الواجهة
─────────────────────
  افتح ملف index.html في أي متصفح ويب.

الخطوة 2: إضافة الروابط
────────────────────────
  1. في قسم "إدارة الروابط"، الصق روابط يوتيوب (كل سطر رابط).
  2. اضغط زر "تنظيف + تصنيف الروابط".
  3. سيتم:
     - إزالة معاملات التتبع (?si=، &feature=، إلخ)
     - تحويل روابط youtu.be إلى youtube.com
     - توليد وسم تلقائي للموقع (#youtube)
     - توليد مجلد ووسم حسب المسار (مثل #shorts)
     - تحديد نوع الرابط (فيديو، قائمة، قناة، شورت)

الخطوة 3: جلب العناوين (اختياري)
──────────────────────────────────
  اضغط زر "جلب عناوين الفيديوهات من يوتيوب" لاستخراج
  عنوان كل فيديو تلقائياً من يوتيوب.

الخطوة 4: تعديل البيانات (اختياري)
───────────────────────────────────
  يمكنك تعديل:
  - الوسم الرئيسي لكل رابط
  - المجلد
  - الأوسمة الإضافية
  - التاريخ (يتم حساب الأسبوع تلقائياً)

الخطوة 5: حفظ البيانات
──────────────────────
  أ) حفظ كـ urls.txt:
     - اضغط "حفظ كـ urls.txt" لتنزيل ملف نصي بالروابط فقط.
  
  ب) تصدير JSON كامل:
     - اضغط "تصدير بيانات الوسوم (JSON)" لتنزيل ملف يحتوي على:
       * كل الروابط
       * الوسوم والمجلدات
       * العناوين
       * التواريخ

الخطوة 6: استيراد البيانات لاحقاً
───────────────────────────────────
  - اضغط "استيراد بيانات"
  - اختر ملف JSON المحفوظ سابقاً
  - سيتم تحميل كل البيانات للواجهة

الخطوة 7: توليد سكربت بايثون
─────────────────────────────
  1. في قسم "توليد كود الأداة"، عدّل الإعدادات حسب حاجتك.
  2. اضغط "توليد / تحديث كود البايثون".
  3. اضغط "نسخ الكود".
  4. احفظ الكود في ملف youtube_archiver.py

الخطوة 8: تشغيل سكربت بايثون
─────────────────────────────
  افتح الطرفية (Terminal/CMD) ونفّذ:
  
  pip install yt-dlp
  python youtube_archiver.py --urls-file urls.txt --output-dir archive

================================================================================
                           الميزات الرئيسية
================================================================================

1. تنظيف الروابط
   ─────────────
   • حذف معاملات التتبع: ?si=, &feature=, &fbclid=, &gclid=
   • الحفاظ على المعاملات المهمة: v (معرّف الفيديو), list, t
   • تحويل youtu.be → youtube.com/watch?v=
   • إزالة التكرار تلقائياً

2. التصنيف التلقائي
   ─────────────────
   • وسم الموقع: #youtube, #vimeo, إلخ
   • وسم المسار: #shorts, #playlist, #channel
   • المجلد: shorts, videos, channel
   • نوع الرابط: فيديو، قائمة تشغيل، قناة، شورت

3. التصنيف الزمني
   ───────────────
   • استخراج التاريخ من الرابط إن وُجد
   • إمكانية تحديد تاريخ يدوي
   • حساب الأسبوع تلقائياً
   • تصنيف "بدون تاريخ" للروابط بدون تاريخ محدد

4. جلب العناوين
   ────────────
   • استخدام YouTube oEmbed API
   • جلب عنوان كل فيديو تلقائياً
   • حفظ العناوين في JSON

5. التخزين المحلي
   ──────────────
   • حفظ تلقائي في LocalStorage
   • البيانات لا تُحذف عند إغلاق الصفحة
   • إمكانية العمل على دفعات متعددة

6. التصدير/الاستيراد
   ─────────────────
   • تصدير JSON كامل مع كل البيانات
   • استيراد من أي جهاز
   • مواصلة العمل من حيث توقفت

================================================================================
                          الأسئلة الشائعة
================================================================================

س: هل أحتاج اتصال بالإنترنت؟
ج: نعم، لـ Tailwind CSS CDN ولجلب عناوين الفيديوهات.

س: أين تُحفظ البيانات؟
ج: في LocalStorage داخل المتصفح + ملف JSON عند التصدير.

س: هل يمكن نقل البيانات لجهاز آخر؟
ج: نعم، صدّر JSON ثم استورده على الجهاز الآخر.

س: ما الفرق بين urls.txt و JSON؟
ج: urls.txt يحتوي الروابط فقط، JSON يحتوي كل البيانات.

س: هل الأداة آمنة؟
ج: نعم، كل شيء يعمل محلياً في متصفحك، لا يُرسل شيء لأي خادم.
