تصميم أداة بايثون لأرشفة فيديوهات يوتيوب

كل ما تحتاجه لصناعة سكربت بايثون متكامل مع إدارة روابط ذكية: تنظيف معاملات ?si=, تحويل روابط youtu.be تلقائياً، تصنيف بالمجلدات والوسوم، وسم باسم الموقع، إضافة تصنيف زمني (يوم/شهر/سنة + أسبوع) مع حفظ واستيراد البيانات.

وسوم تلقائية + مجلدات + موقع تصنيف زمني: يوم / أسبوع دليل شامل مع شرح كل سطر

1. الفكرة العامة للأداة

سكربت بايثون يعتمد على yt-dlp لأرشفة عدد كبير من الروابط مع تنظيم كامل:

  • قراءة الروابط من ملف (مثل urls.txt) أو من الواجهة أدناه.
  • تنظيف معاملات ?si= وباقي تتبّعات يوتيوب + تحويل youtu.be إلى youtube.com.
  • تحميل الفيديو + الصوت بأعلى جودة مع استكمال تلقائي.
  • حفظ ميتاداتا (JSON، ترجمة، صورة مصغرة) اختيارياً.
  • سجل (log) لعمليات النجاح والفشل مع إمكانية الاستكمال.
  • توليد وسوم متعددة: وسم الموقع (#youtube)، وسم المسار (مثل #shorts)، ومجلد تلقائي.
  • تصنيف زمني لكل رابط (يوم/شهر/سنة + الأسبوع)، مع خيار "بدون تاريخ".

أوامر تشغيل نموذجية

# مثال لتشغيل الأداة:

python youtube_archiver.py \

--urls-file urls.txt \

--output-dir ./archive \

--max-concurrent 2 \

--format bestvideo+bestaudio

2. توليد كود الأداة حسب إعداداتك

عدّل الإعدادات ثم انسخ كود بايثون الناتج بالأسفل.

الكود الناتج (youtube_archiver.py)

قاعدة بيانات الروابط

قاعدة بيانات الروابط: كل الروابط تُحفظ في الجدول أدناه. استخدم خانة الإدخال لإضافة روابط جديدة، وسيتم تنظيفها وتصنيفها تلقائياً ثم إضافتها للقاعدة. يمكنك تصدير قاعدة البيانات كملف JSON للاحتفاظ بها، واستيرادها لاحقاً من أي جهاز.

مثال تلقائي كامل:

الرابط: https://youtube.com/shorts/myOWyk7_8Aw?si=xyz

بعد التنظيف: https://youtube.com/shorts/myOWyk7_8Aw

وسم الموقع: #youtube — المجلد: shorts — الوسم التلقائي: #shorts

التاريخ: يتم استخراجه من الرابط إن وجد وإلا يوضع "بدون تاريخ".

ملاحظات مهمة:
  • لا يتم تغيير دومين يوتيوب، فقط إزالة معاملات مثل ?si=.
  • إذا لم يكن هناك مسار صالح بعد youtube.com/ (مثل /_gYIWm_v19U) يتم تصنيفه تلقائياً ضمن #videos.
  • يمكن إضافة أوسمة مخصصة، وتحديد تاريخ يدوي لفرز أسبوع/يوم.
  • تصدير/استيراد JSON يحافظ على الوسوم والمجلد والموقع والتاريخ.
طريقة العمل:
  • خانة الإدخال أعلاه: لإضافة روابط جديدة فقط (ستُفرغ بعد الإضافة)
  • الجدول أدناه: هو قاعدة البيانات الفعلية التي تحتفظ بكل الروابط
  • التصدير: يحفظ كل البيانات من الجدول في ملف JSON
  • الاستيراد: يحمّل بيانات من ملف JSON إلى الجدول

ملاحظة: يتم حفظ كل بيانات الروابط (العناوين، الوسوم، المجلدات، والتاريخ) داخل ملف JSON واحد يمكنك تنزيله عند الضغط على زر "تصدير بيانات الوسوم"، ثم الاحتفاظ به على جهازك دون أن تُحذف البيانات من الصفحة. لاحقاً يمكنك تعديل هذا الملف أو نقله إلى جهاز آخر ثم استخدام زر "استيراد بيانات" لإعادة تحميله إلى الواجهة ومواصلة العمل عليه. شكل الملف مشابه للملف النموذجي links_data.json المرفق مع هذه الصفحة.

💡 ملاحظات:
  • الجدول أدناه هو قاعدة البيانات الفعلية - كل تعديل يُحفظ تلقائياً
  • يمكنك حذف أي رابط بالضغط على زر 🗑️ بجانبه
  • استخدم تصدير JSON لحفظ نسخة احتياطية على جهازك
  • استخدم استيراد لتحميل بيانات من ملف JSON سابق

4. شرح سريع لما يفعله السكربت

  1. يقرأ ملف الروابط (كل سطر = رابط فيديو أو قائمة أو قناة).
  2. ينظف الملف من السطور الفارغة والتعليقات.
  3. ينشئ مجلد الأرشيف إن لم يكن موجوداً.
  4. لكل رابط، يشغّل yt-dlp بالإعدادات المختارة ويستكمل تلقائياً.
  5. يحاول الاستمرار حتى لو حدثت أخطاء لرابط معيّن.
  6. يسجل النتائج في ملف archive.log داخل مجلد الإخراج.

ملف الروابط (urls.txt مثال):

# يمكن أن يحتوي على فيديوهات، قوائم، قنوات
https://www.youtube.com/watch?v=VIDEO_ID_1
https://www.youtube.com/watch?v=VIDEO_ID_2

# قائمة تشغيل كاملة
https://www.youtube.com/playlist?list=PLAYLIST_ID

# قناة كاملة (سيتم أرشفة كل الفيديوهات)
https://www.youtube.com/@channel_name

تشغيل السكربت:

# تثبيت yt-dlp (مرة واحدة)
pip install yt-dlp

# تشغيل الأداة بالإعدادات الافتراضية
python youtube_archiver.py

# تشغيل مع تحديد ملف مختلف
python youtube_archiver.py \
  --urls-file my_urls.txt \
  --output-dir D:/YouTubeArchive \
  --max-concurrent 4
